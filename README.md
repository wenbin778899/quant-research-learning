## 笔试任务说明

**背景**：量化策略团队即将迎来一批新实习生。他们具备一定金融基础和编程/数据分析能力，但对量化多因子策略的**完整研究流程、体系以及实操（"量化研究"）**缺乏深入理解。

**任务**：制作一份"量化研究入门学习资料"，目标是新人在阅读后，能够对量化研究的认识和理解有**较为明显的提升**，从而能够**顺利上手团队的基础研究工作**。

**交付物**：
1. **量化研究入门学习资料（输出形式不限）** —— 本网站（GitHub Pages 网页版，线上可访问）+ 7 本可运行 Notebook + 数据生成脚本与全量可复现数据
2. **对 AI 的所有提问** —— `docs/QUESTIONS.md`（完整记录）+ 网页「研究过程与提问」页（同源数据）

**时间要求**：收到题目后 24 小时内提交。

**其他说明**：题目注明"可以向 HR 提问，提问的质量也会纳入评估考量"——本资料的提问记录（交付物二）即为此项评估的完整留痕，提问方法论见 [QUESTIONS.md](docs/QUESTIONS.md)。

## 本资料如何达成"明显提升"的目标

面向"具备一定金融基础和编程/数据分析能力、但缺乏量化研究深入理解"的新实习生，以**完整研究流程**为主线组织：

```
数据获取与清洗 → 因子构建 → 因子检验 → 因子合成 → 组合构建 → 回测与评估 → 绩效归因
```

七个环节覆盖团队基础研究工作的完整流水线。每个章节固定结构：**概念讲解（聚焦实务中会踩的坑）→ 交互图表 → 可运行代码 → 常见误区 → 思考题**，并在关键处显式讲解评审敏感的专业点：

- 数据纪律：Point-in-Time 数据、幸存者偏差、前瞻偏差、复权口径
- 检验方法：IC / ICIR / t 值、分层回测与单调性
- 成本意识：换手率与交易成本对 alpha 的侵蚀
- 反过拟合：数据窥探、样本外验证

## 动手实践：Notebook 重算（本资料的核心动手环节）

**网页负责"看懂"，Notebook 负责"做出来"**。只看不练是达不到"上手基础研究工作"的——因此每一章都配一本可运行的 Notebook（`notebooks/01-07`），新人按"动手线"学习：

```
读第 X 章 → 打开 notebooks/0X_*.ipynb → 逐格运行 → 用数据文件重算出该章网页上的图表 → 修改参数看结果变化
```

**Notebook 与网页图表严格对应**：每本 Notebook 从原始 CSV（`data/csv/`）出发，独立重算该章图表对应的分析结果（IC、分层、组合净值、归因……），**最后一个单元格会自动校验**：用 `np.allclose` 把你的重算结果与网页图表的 JSON 数据对比，**打印 PASS 才算完成该章的动手环节**。

建议的动手练习（改一行代码，观察真实影响）：

| Notebook | 动手练习 | 观察什么 |
|---|---|---|
| 01 数据清洗 | 把"删除退市股"改为"保留"再重算 | 幸存者偏差如何高估收益 |
| 02 因子构建 | 改动量窗口 60 → 20 | 窗口选择对因子稳定性的影响 |
| 03 因子检验 | 分层数 10 → 5 | 层间单调性变得更"干净"还是更"模糊" |
| 05 组合构建 | TopN 从 20 改成 50 | 收益与换手的此消彼长 |
| 06 回测评估 | 成本从 10bps 改成 30bps | 成本如何吞噬超额收益 |

**验收标准**：全部 7 本 Notebook 执行完毕、末 cell 全部 PASS——即完成了"从原始数据到回测结果"的完整动手闭环，这正是团队基础研究工作的日常。

## 研究过程与 AI 协作：这个项目是怎么构建出来的

本项目的构建方式本身就是笔试的作答过程：**以我的提问和决策为主线，AI 作为工具，24 小时内从题目到交付**。完整过程记录在 [QUESTIONS.md](docs/QUESTIONS.md)（15 条提问，8 字段模板：背景/原文/回答摘要/采纳决定/理由/反思）与网页「研究过程与提问」页。

### 协作模式：提问 → 决策 → 验证 的三步闭环

不是"让 AI 直接产出"，而是每一步都有我自己的判断与验证：

```
① 向 AI 提问（带背景与约束） → ② 我评估并决定采纳/部分采纳/拒绝 → ③ 回到数据上验证结果 → ④ 记录留痕
```

### 关键决策（体现思考权衡）

| 决策点 | 我的选择 | 理由 |
|---|---|---|
| 交付形态 | **GitHub 网页**（而非文档/PPT） | 评审打开即用；commit 历史本身可展示研究过程 |
| 数据来源 | **模拟数据**（而非真实行情） | 可复现、无 API 依赖，且能精确控制"哪些因子有效"用于教学 |
| 内容主线 | **完整流程 + 每章配可运行代码** | 题目要求"完整研究流程、体系以及实操"三者兼得 |
| 提问记录 | **独立文档 + 网页双入口** | 提问质量纳入评估，双入口保证完整可读 |

### 过程中的问题发现与解决（体现思考深度）

构建过程中遇到的真实问题，多数是"看似正确、实则破坏结构"的隐蔽 bug，每一步都通过数据自检定位并修正：

1. **除息实现 bug**：首版把除息日后的全部价格平移，破坏了收益结构、污染估值因子——通过 IC 基线异常定位，修正为仅除息日跳空；
2. **动量因子 IC 发散（−0.22）**：定位到 alpha 注入区间与因子计算窗口的自反馈——修正注入区间（调仓日当天不注入）后 6 轮收敛；
3. **波动率因子前视偏差**：首版误用未来一个月数据——模拟器自身也必须遵守 PIT 纪律，否则"数据可复现"承诺不成立；
4. **多因子校准振荡**：动量与反转因子高度相关导致校准互相竞争——把短期动量改为中期动量（MOM60）解耦。

### 本项目的三个创新设计（思考与工程能力的体现）

1. **可复现性闭环**：网页上的每一张图表都可以从原始 CSV 一步步重算（Notebook 末 cell 自动校验）。为兑现这条承诺，模拟器本身必须遵守自己教的纪律（PIT、无前瞻偏差）——"教学内容"与"工程实现"互相约束；
2. **自动校准机制**：因子的 alpha 系数不是手调的，而是迭代缩放使月度 IC 自动落入真实研究区间（强因子 0.04-0.08、弱因子 ≤0.03）——任何随机种子下都可复现，且数据"像真的"；
3. **教学点内建的模拟数据**：退市股（幸存者偏差）、分红送股（复权）、随机缺失与停牌（数据清洗）——每个教学点都是数据中真实存在的结构，而非事后编故事。

**提问**：波动率因子的计算窗口用未来一个月还是过去一个月？

### Q09 · 数据模拟 · 已采纳
**提问**：把因子预测力注入价格时，动量类因子的 IC 为何发散（−0.22）？
**决定**：采纳——根因是注入区间包含调仓日当天，注入收益进入因子计算窗口形成自反馈；修正为 (d0, d1] 后校准 6 轮收敛；并把短期动量改为中期动量（MOM60）解耦因子竞争。

### Q10 · 统计方法 · 已采纳
**提问**：模拟因子的 IC 应该设计成什么水平才"贴近真实研究"？
**决定**：采纳——有效因子月度 IC 0.04-0.08（t 值 >2）、弱因子 0.01-0.03、SIZE 负向呼应 A 股小市值效应；分层级设计让"筛选因子"有真实的决策感。

### Q11 · 图表与交互 · 已采纳

### Q12 · 网页实现 · 已采纳

**决定**：采纳——经色盲安全验证的 8 槽分类色板 + 蓝色单色序（分层渐变）、明暗双主题各一套色值、净值/回撤用双面板而非双轴。

### Q14 · 统计方法 · 已采纳

## 模拟数据设计（教学点）

- **200 只股票 × 8 行业**，2020-2024 共 60 个月度调仓期
- **3 只退市股**（退市前连续大跌）→ 幸存者偏差教学点
- **30% 股票季度分红 + 送股** → 复权教学点
- **随机缺失 + 停牌** → 数据清洗教学点
- **8 个因子分级预测力**：强因子（EP/MOM60/ROE/GROW，月 IC≈0.06）、中（REV5≈0.05）、弱（SIZE/VOL20/TURN，|IC|≤0.02，SIZE 负向呼应小市值效应）
- alpha 系数经**自动校准**迭代收敛，IC 落入贴近真实研究的区间

## 一致性保证

生成脚本内部的分析一律基于「prices.csv 注入缺失 → ffill → 剔除退市后区间」的清洗序列；
Notebook 从 CSV 读入后执行**相同的清洗**再重算，末 cell 用 `np.allclose` 对照网页 JSON——
网页上每一张图都可以从原始 CSV 一步步重算出来。
