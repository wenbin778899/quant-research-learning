## 笔试任务说明

**背景**：量化策略团队即将迎来一批新实习生。他们具备一定金融基础和编程/数据分析能力，但对量化多因子策略的**完整研究流程、体系以及实操（"量化研究"）**缺乏深入理解。

**任务**：制作一份"量化研究入门学习资料"，目标是新人在阅读后，能够对量化研究的认识和理解有**较为明显的提升**，从而能够**顺利上手团队的基础研究工作**。

**交付物**：
1. **量化研究入门学习资料（输出形式不限）** —— 本网站（GitHub Pages 网页版，线上可访问）+ 7 本可运行 Notebook + 数据生成脚本与全量可复现数据
2. **对 AI 的所有提问** —— `docs/QUESTIONS.md`（完整记录）+ 网页「研究过程与提问」页（同源数据）

**时间要求**：收到题目后 24 小时内提交。

**其他说明**：题目注明"可以向 HR 提问，提问的质量也会纳入评估考量"——本资料的提问记录（交付物二）即为此项评估的完整留痕，提问方法论见 [QUESTIONS.md](docs/QUESTIONS.md)。

## 本资料如何达成"明显提升"的目标

面向"具备一定金融基础和编程/数据分析能力、但缺乏量化研究深入理解"的新实习生，以**完整研究流程**为主线组织：

```
数据获取与清洗 → 因子构建 → 因子检验 → 因子合成 → 组合构建 → 回测与评估 → 绩效归因
```

七个环节覆盖团队基础研究工作的完整流水线。每个章节固定结构：**概念讲解（聚焦实务中会踩的坑）→ 交互图表 → 可运行代码 → 常见误区 → 思考题**，并在关键处显式讲解评审敏感的专业点：

- 数据纪律：Point-in-Time 数据、幸存者偏差、前瞻偏差、复权口径
- 检验方法：IC / ICIR / t 值、分层回测与单调性
- 成本意识：换手率与交易成本对 alpha 的侵蚀
- 反过拟合：数据窥探、样本外验证

新人按"通读线"（约 4-6 小时）完成七个章节后，可理解团队基础研究的标准流程、看懂一份因子检验报告、并能从原始数据一步步重算出回测结果——对应题目要求的"顺利上手基础研究工作"。

## 快速开始

```bash

pip install -r scripts/requirements.txt

# 2. 生成全部数据（含自检报告）
python scripts/generate_data.py

# 3. 本地预览
python -m http.server 8000
# 打开 http://localhost:8000/

# 4. （可选）执行 notebook 一致性校验
python scripts/make_notebooks.py        # 重新生成 notebook
jupyter nbconvert --to notebook --execute notebooks/*.ipynb   # 或逐本执行
```

## 模拟数据设计（教学点）

- **200 只股票 × 8 行业**，2020-2024 共 60 个月度调仓期
- **3 只退市股**（退市前连续大跌）→ 幸存者偏差教学点
- **30% 股票季度分红 + 送股** → 复权教学点
- **随机缺失 + 停牌** → 数据清洗教学点
- **8 个因子分级预测力**：强因子（EP/MOM60/ROE/GROW，月 IC≈0.06）、中（REV5≈0.05）、弱（SIZE/VOL20/TURN，|IC|≤0.02，SIZE 负向呼应小市值效应）
- alpha 系数经**自动校准**迭代收敛，IC 落入贴近真实研究的区间

## 一致性保证

生成脚本内部的分析一律基于「prices.csv 注入缺失 → ffill → 剔除退市后区间」的清洗序列；
Notebook 从 CSV 读入后执行**相同的清洗**再重算，末 cell 用 `np.allclose` 对照网页 JSON——
网页上每一张图都可以从原始 CSV 一步步重算出来。
