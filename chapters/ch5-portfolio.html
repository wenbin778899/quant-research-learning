第 5 章 组合构建

学习目标：从因子分数到持仓 · 权重方案 · 约束与成本 · 基准选择 图表：C16-C18代码：notebook 05

因子研究的最终产出是持仓。本章把合成因子变成一个可实盘的组合：选多少只、怎么配权重、加什么约束、成本吃掉多少收益。

5.1 从因子分数到持仓

最朴素也最常用的做法：排序选股——每期调仓日按合成因子分数从高到低排序，取前 N 只（本资料：前 20 只 ≈ Top 10%），等权持有。为什么不用"每期全市场都配"？因为因子的预测力集中在高分段，尾部是噪声；也便于控制换手。

进阶方案（本资料不讲细节）：优化器求解权重——在约束下最大化组合因子暴露或最大化预期收益，如 Barra 风险模型 + 均值-方差优化。

5.2 权重方案与组合结构

C16 · 最新一期组合持仓结构（Top20 等权）
左：个股权重；右：组合行业分布
怎么看：等权组合每只 5%；行业分布是"选股的自然结果"——若某行业权重远超其基准占比（约 12.5%），说明组合无意中做了行业下注（风险归因见第 7 章）。

5.3 组合约束：控制你不想承担的风险

  • 行业权重约束：单行业上限（如 ≤ 基准占比 + 5%），防止行业押注
  • 个股权重上限：单票 ≤ 10%，防止集中风险
  • 风格中性约束：市值/行业暴露归零（与第 2 章中性化同源）

5.4 成本与换手：alpha 的头号敌人

因子换手越频繁，交易成本越重。A 股的实际成本构成：

  • 佣金：约 1-3 bps/边
  • 印花税：卖出 5 bps（2023.8 起减半）
  • 冲击成本：按成交量的比例，小票可达 20-50 bps

本模拟组合的月度换手约 60-130%（合成因子相邻期重叠少）——这个量级下，单边 20 bps 的成本足以吃掉大部分超额收益：

C17 · 月度换手率（60 期）
换手 = 买卖股数之和 / 持仓数；虚线为均值
怎么看：换手率在 60%-140% 间波动。均值线上的标注——如果换手主要由噪声因子驱动，降换手（如加约束）可以显著提升净值。
C18 · 成本敏感性（0/5/10/20 bps 四档）
单边成本；同策略仅成本假设不同
怎么看：0 成本年化收益与 20 bps 年化收益的差距，就是"理论 alpha"与"可交易 alpha"的距离。评审必问："你测过扣费后的表现吗？"

5.5 基准选择：你的策略和谁比

基准适用场景注意
沪深 300大盘蓝筹风格策略小市值策略跑赢它"太容易"，无信息量
中证 500 / 1000中小盘策略（本资料股票池风格）与股票池市值分布匹配
全市场等权研究期的中性参照本资料使用等权全样本作基准——便于归因

基准应与股票池同源同域：用中证 1000 成分股做策略，却和沪深 300 比超额，是常见的新手错误。

5.6 核心代码：组合构建

def build_portfolio(factors, top_n=20):
    """每期按合成因子取 Top N 等权，返回持仓与换手"""
    holds = []
    for t, g in factors.groupby("date"):
        g = g.dropna(subset=["next_return"])
        pick = g.nlargest(top_n, "z_composite")["code"].tolist()
        holds.append(pick)
    # 换手率 = 两期持仓差异
    turn = [len(set(holds[t]) - set(holds[t-1])) * 2 / top_n for t in range(1, len(holds))]
    return holds, turn

# 成本敏感性：净值 × (1 − 换手 × 单边成本)
def apply_cost(nav, turn, cost_bps):
    cost = cost_bps * 1e-4
    adj = [1.0]
    for t in turn:
        adj.append(adj[-1] * (1 - t * cost))
    return nav * adj

常见误区

误区一：只看毛收益不看换手

年化 40% 毛收益、月换手 150% 的策略，扣 10 bps 成本后可能只剩 20%。换手率必须和收益一起报告。

误区二：过度集中

Top 5 集中持仓收益波动巨大，且隐含"因子分数最高的 5 只最有把握"的过度自信。

误区三：行业/市值暴露不设防

组合实际押注行业或小市值风格——风格切换时莫名回撤，归因（第 7 章）会把你拆穿。

思考题

  1. Top N 从 20 变 50，预期收益和换手会如何变化？"最优" N 应该怎么定？
  2. 如果合成因子在相邻两期的排序几乎不变，换手率会很低——你希望因子"稳定"还是"敏锐"？
  3. 冲击成本对大盘股和小盘股差异很大——同样 5% 个股权重，策略容量由谁决定？
