因子构建完成只是开始——90% 的因子在检验环节被淘汰。检验回答四个问题：有效吗？稳定吗？单调吗？独立吗？

3.1 检验的四维目标

维度问什么主要工具
有效性因子值高 → 未来收益高？IC 均值、分层多空收益
稳定性每个月都有效，还是某几个月爆发？IC 序列、ICIR、IC>0 胜率
单调性收益随因子值单调上升（而非只在两端有效）？分层回测（10 组净值）
独立性与已有因子冗余吗？因子相关性矩阵（第 4 章）

3.2 IC 分析：因子与未来收益的相关性

IC（Information Coefficient）= 每期截面上，因子 z 值与未来一期收益的相关系数。两个口径：

  • Pearson IC：线性相关——对极端值敏感
  • Rank IC（Spearman）：排序相关——更稳健，实践中更常用

三个汇总统计（团队评审必问）：

  • IC 均值：平均预测力。经验阈值：月度 |IC| > 0.03 才算"有可用性"
  • ICIR = mean(IC)/std(IC)：单位风险的预测力——比 IC 均值更重要
  • t 值 = mean(IC)/(std(IC)/√N)：IC 显著性的统计检验，|t| > 2 说明不是运气

本资料的 8 个模拟因子被刻意设计为三个层级：强因子（EP/MOM60/ROE/GROW，月 IC ≈ 0.06）、中等（REV5 ≈ 0.05）、弱因子（SIZE/VOL20/TURN，|IC| ≤ 0.02）。下面的图表可以用因子选择器逐一查看。

3.3 分层回测：最直观的有效性证据

把每期股票按因子值分 10 层（十分位），计算每层持有下个月的收益并累积为净值。三个观察点：

  • 层间单调性：层 1 → 层 10 净值是否单调展开——单调说明因子"越有效越好用"
  • 多空价差：层 10 − 层 1（多空组合）——扣除市场后的纯因子收益
  • 两端是否收敛：中间层挤在一起、只有两端分开 → 因子只在极端处有效（容量小、易失效）
C11 · 十分位分层累计净值（单色序渐变）
图例可勾选单层查看；多空价差（LS）为粗线
怎么看：强因子：10 条线按层号整齐展开、多空向上；弱因子：各层纠缠不分、多空趋平——一眼区分有效与无效。
C12 · 分层平均月收益（层 1-10 + 多空价差）
多空价差柱用强调色高亮
怎么看：有效因子层收益近似单调（SIZE 为负向单调）；弱因子层收益在 0 附近无规律。

3.4 检验的局限：IC 高 ≠ 能赚钱

IC 高只是必要条件

  • 容量：IC 0.08 的因子可能只在少数小市值股票上有效——放不进大资金
  • 换手与成本：高换手因子的 IC 会被交易成本吞噬（第 5 章成本敏感性演示）
  • 数据窥探（Data Snooping）：挖了 1000 个因子，总有几个样本内 t 值过 5——那是多重检验的必然产物，不是真本事
  • 时变性：因子有效性会衰减——今天有效不代表明年有效（第 6 章回测陷阱再讨论）

3.5 核心代码：IC 与分层

import pandas as pd, numpy as np
from scipy import stats

factors = pd.read_csv("data/csv/factors.csv", parse_dates=["date"])

# —— IC 分析 ——
def ic_by_period(factors, zcol="z_EP"):
    ics = []
    for _, g in factors.groupby("date"):
        sub = g[[zcol, "next_return"]].dropna()
        if len(sub) >= 30:
            ics.append(sub[zcol].corr(sub["next_return"]))          # Pearson IC
            # ics.append(sub[zcol].corr(sub["next_return"], method="spearman"))  # Rank IC
    ic = np.array(ics)
    return dict(mean=ic.mean(), std=ic.std(),
                icir=ic.mean() / ic.std(),
                t=ic.mean() / (ic.std() / np.sqrt(len(ic))))

# —— 十分位分层 ——
def layer_returns(factors, zcol="z_EP", n_layers=10):
    rows = []
    for _, g in factors.groupby("date"):
        sub = g[[zcol, "next_return"]].dropna()
        sub["layer"] = pd.qcut(sub[zcol], n_layers, labels=False)   # 每期截面分位
        rows.append(sub.groupby("layer")["next_return"].mean())
    df = pd.DataFrame(rows)                                         # 每行一期
    nav = (1 + df).cumprod()                                        # 层净值
    ls = (1 + df.iloc[:, -1] - df.iloc[:, 0]).cumprod()             # 多空价差
    return df, nav, ls

常见误区

误区一：只看 IC 均值，不看稳定性

IC 均值 0.05 但标准差 0.15（ICIR 0.33）的因子，一半月份在反向失效。评审标准：ICIR > 0.5、t > 2 是入门线。

误区二：用日频 IC 冒充月频

日频 IC 的样本量大，t 值天然虚高。与策略调仓频率匹配的检验频率才有意义（月度调仓 → 月频 IC）。

误区三：分层只看两端

只报告"多空年化 30%"而层间不单调的因子，实际选股时中间层贡献为 0——必须看全部 10 层。

思考题

  1. 为什么分层回测用十分位而不是五分位？样本量 200 只时十分位的单层只有 20 只，收益估计误差如何？
  2. REV5 因子 t 值 2.5、IC 0.05，但换手率接近 200%/月——你会采纳它吗？还要看什么？
  3. 累积 IC 线中途拐头，可能是哪两类原因？如何区分？
