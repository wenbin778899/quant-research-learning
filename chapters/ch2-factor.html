第 2 章 因子构建

学习目标：理解因子的本质 · 掌握 8 个示例因子的定义 · 标签对齐 · 标准化与行业中性化 图表：C6-C7代码：notebook 02

因子是"能预测横截面收益的特征"。本章解决三个问题：什么是好因子、怎么计算、怎么让因子可比。

2.1 什么是因子：定价因子 vs 预测因子

多因子研究的理论基础是套利定价理论（APT）：股票收益由一系列共同风险因子驱动。实践中我们构建两类因子：

  • 定价因子（Risk Factor）：解释收益的风险来源——如 Fama-French 三因子的市场/规模/价值。研究目的是"解释"，对应第 7 章归因。
  • 预测因子（Alpha Factor）：预测未来横截面收益——如"低估值股票未来跑赢"。研究目的是"预测"，对应第 3 章检验。

团队基础研究里说的"挖因子"，绝大多数是预测因子。一个预测因子必须回答：为什么它在逻辑上能预测收益？（经济逻辑）——纯粹数据挖掘出来的因子即使样本内有效，样本外也大概率失效。

2.2 八个示例因子的业务逻辑

本资料使用 8 个模拟因子，覆盖基本面与量价两大族，并刻意设计了不同的"真实预测力"（第 3 章检验时可以看到差异）：

因子族定义业务逻辑方向
EP估值每股收益 / 价格便宜的好公司被低估（价值溢价）正
SIZE规模ln(总市值)A 股小市值效应（壳价值/低关注）负
MOM60量价过去 60 日收益率中期动量：趋势延续正
REV5量价−过去 5 日收益率短期反转：超跌反弹正
VOL20量价−过去 20 日波动率低波动异象：高波动股被高估正
TURN流动性−月均换手率低换手：筹码稳定/关注度低正
ROE基本面净资产收益率质量溢价：高盈利公司持续跑赢正
GROW基本面营收增速成长溢价正

注意因子方向的定义

上表的方向是"因子值越高 → 未来收益越高"的预期方向。SIZE 是负向因子（小市值未来收益高），实际使用时通常取负或排序反向。数据里我们统一把因子做成"方向标准化"（第 2.4 节），负向因子直接取负号处理。

2.3 计算细节：窗口与标签对齐

因子计算有两个最容易出错的细节：

  • 窗口必须严格历史：MOM60 用调仓日前 60 个交易日，VOL20 用前 20 个交易日——用未来数据就是第 1 章讲的前瞻偏差。
  • 标签对齐（最关键）：t 期因子（调仓日 d₀ 计算）预测 t 期到 t+1 期（d₀ → d₁）的收益。收益标签 = close[d₁]/close[d₀] − 1，与因子严格错开一期——这是"因子预测未来"的标准口径。

全部 8 个因子的 z 值按调仓期存放于 data/csv/factors.csv（z_EP、z_SIZE…），并附 next_return 标签列，供第 3-7 章直接使用。

2.4 标准化：让因子可以跨期、跨因子比较

原始因子值不可直接比较：EP 是 0.05-0.3 的小数，SIZE 是 15-25 的对数市值。三件套预处理：

  1. 去极值（Winsorize）：超出均值 ±3σ 的截断——防止极端值主导排序
  2. 截面标准化（z-score）：每期每因子减去截面均值、除以截面标准差 → 均值为 0、标准差为 1
  3. （可选）排名法：直接取截面百分位排名，更稳健（天然抵抗异常值）

2.5 中性化：剥离已知风险后剩下的才是 alpha

行业中性化是最重要的一步：如果你持有"医药行业因子"而非"医药行业内选股能力"，组合就暴露在行业风险下。做法：把因子值对行业哑变量回归，取残差——残差就是"行业内相对强弱"。

为什么要中性化？

假设"银行股普遍便宜"（EP 高）但银行整体跑输——不做行业中性化，EP 因子看起来"有效"（高 EP 股跑输）或"无效"（被行业拖累），真实原因是行业配置而非选股。中性化后，因子衡量的是"行业内哪只更便宜"，这才对应选股 alpha。

C7 · 行业中性化效果（EP 因子按行业分组箱线）
左：仅标准化（行业均值明显分层）；右：中性化后（各行业均值对齐 0）
怎么看：中性化前，不同行业的 EP 因子均值差异显著（某些行业整体"便宜"）；中性化后各行业箱体居中于 0——因子不再携带行业信息。

2.6 核心代码：因子计算与预处理

完整代码见 notebooks/02_factor_construction.ipynb。核心逻辑：

def compute_factors(close, rebal_dates, window=60):
    """调仓日截面因子计算（严格历史窗口，无前瞻偏差）"""
    out = {}
    for d0 in rebal_dates:
        i0 = close.index.get_loc(d0)
        px = close.iloc[i0]
        mom = px / close.iloc[i0 - window] - 1      # 60 日动量
        vol = -close.iloc[i0 - 20:i0].std()          # 20 日波动率（负号 → 低波动因子）
        out[d0] = {"MOM60": mom, "VOL20": vol, "EP": eps / px, ...}
    return pd.DataFrame(out).T

def winsorize(x, n=3):
    m, s = x.mean(), x.std()
    return x.clip(m - n * s, m + n * s)

def neutralize(x, industries):
    """行业中性化：对行业哑变量回归取残差（等价于减去行业均值）"""
    dummies = pd.get_dummies(industries)
    return x - dummies @ (dummies.T @ dummies).inv() @ dummies.T @ x  # 或直接减行业均值

常见误区

误区一：因子计算用了未来数据

典型症状：因子 IC 异常高（>0.15）。自查：动量窗口、波动率窗口、财务数据披露日期是否严格 ≤ 调仓日。

误区二：标签错位

把 t 期因子配了 t 期收益（同期相关），看起来"有效"实则是伪相关。标准口径：因子 t 期、收益 t→t+1 期。

误区三：因子不平滑直接合成

未去极值、未标准化的因子直接等权合成，极端值主导合成分数。预处理必须每个因子、每期截面都做。

思考题

  1. SIZE 是负向因子，如果你直接把它和其他正向因子等权合成，会发生什么？合成前应该怎么处理方向？
  2. 行业中性化会损失因子信息吗？什么情况下"不做中性化"反而是对的？
  3. 财务因子（ROE）在 4 月底披露年报——如果 2 月就用上年年报数据构建 ROE 因子，犯了什么错？如何修正？
