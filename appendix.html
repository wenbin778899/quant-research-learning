胜率跑赢基准（或正收益）的期数占比

复现说明

# 1. 环境
pip install -r scripts/requirements.txt     # numpy / pandas / scipy

# 2. 一键复现全部数据（CSV + JSON，固定种子 SEED=42）
python scripts/generate_data.py
# 输出：data/csv/*.csv + data/*.json，并运行自检（IC 区间/分层单调/净值正性/退市标记）

# 3. 网页本地预览
python -m http.server 8000                  # 浏览器打开 http://localhost:8000/

# 4. Notebook 校验
# 每个 notebook 的最后一个 cell 会用 np.allclose 对照 data/*.json，
# 全部打印 PASS 即证明网页图表数据可完整复现。

一致性保证机制

生成脚本内部的分析全部基于「prices.csv 注入缺失后 ffill 填充、剔除退市后区间」的序列；Notebook 从 CSV 读入后执行同样的清洗再重算——两条路径得到相同的数值，末 cell 用 np.allclose 对照网页 JSON。这一设计保证：网页上每一张图都可以从原始 CSV 一步步重算出来。

常见问题

Q：数据是真实的吗？ 否。全部为模拟数据（对数正态收益 + 注入真实研究中的教学结构：退市、分红、停牌、缺失、因子预测力分层）。模拟参数与校准过程见 scripts/generate_data.py 注释。Q：为什么不用真实 A 股数据？ 模拟数据完全可复现、无 API 依赖、且能精确控制"哪些因子有效、有效到什么程度"——教学上比真实数据的"噪声大、结构未知"更适合入门。
