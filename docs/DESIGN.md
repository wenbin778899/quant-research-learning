# 设计方案

> 《量化研究入门学习资料》项目设计文档（与 `docs/QUESTIONS.md` 配套，记录设计决策过程）

## 1. 项目定位

面向"具备金融基础 + Python 能力、但不熟悉量化多因子研究流程"的新实习生，交付一套
以完整研究流程为主线、**概念 + 代码 + 交互图表**三位一体的学习资料。

三个维度共同构成笔试评分支撑：

| 维度 | 体现 |
|---|---|
| 内容深度 | 完整研究流程 + 实务坑（PIT/幸存者偏差/前瞻偏差/ICIR/过拟合） |
| 工程严谨 | 数据全模拟可复现、Notebook 一致性校验闭环、自动校准 |
| 提问质量 | QUESTIONS.md + 网页提问页（8 字段模板，原文留痕） |

## 2. 关键设计决策（含权衡）

### 2.1 网页形式：纯静态多页面 + ECharts

| 方案 | 结论 |
|---|---|
| 单页滚动 | 内容 10 页规模下单页 HTML > 2MB，首屏慢、维护差 |
| 多页面（选用） | 每页只加载本章 JSON（<300KB），导航清晰，一章一文件 |
| MkDocs / Jupyter Book | 增加构建步骤，与 24h 时限和"零构建"冲突 |

ECharts 本地化（vendored 1MB）+ CDN 兜底：评审网络环境不可控时仍可离线渲染。

### 2.2 数据：模拟而非真实

- **可复现**：固定种子（SEED=42），一条命令重跑全部数据
- **可控**：精确设计"哪些因子有效、有效到什么程度"（IC 分级）
- **教学点内建**：退市（幸存者偏差）、分红（复权）、停牌/缺失（清洗）

alpha 校准机制：迭代缩放 alpha 使各因子月度 IC 落入目标区间
（强因子 0.04-0.08 / 弱因子 ≤0.03，SIZE 负向），任何 seed 均可复现且贴近真实研究水平。

### 2.3 内容主线：全流程体系

数据 → 因子 → 检验 → 合成 → 组合 → 回测 → 归因，每章固定结构：
学习目标 → 概念（实务坑导向）→ 图表 → 代码 → 常见误区 → 思考题 → 章节衔接。

深度体现点（评审敏感处，均显式成节）：
Point-in-Time 数据、幸存者偏差、前瞻偏差、复权方式、ICIR/t 值、分层单调性、
换手与成本、数据窥探与过拟合。

### 2.4 可复现性承诺（本设计最重要的约束）

**网页上的每一张图都可以从原始 CSV 一步步重算**。实现：

1. 生成器内部一切分析基于「prices.csv 注入缺失 → ffill → 剔除退市后区间」的清洗序列
2. Notebook 从 CSV 读入 → 相同清洗 → 独立重算
3. 末 cell 用 `np.allclose` 对照网页 JSON（atol 匹配 CSV 存储精度）

这条承诺反过来约束了模拟器本身：因子窗口必须严格历史（无前瞻偏差）、
注入区间不能污染调仓日价格（无自反馈）——**模拟器必须遵守自己教的纪律**。

### 2.5 提问记录：并列交付物

- 独立 `docs/QUESTIONS.md`（交付物本体）+ 网页 `process.html`（同源 `questions.json`）
- 8 字段模板：背景 / 原文 / AI 回答摘要 / 采纳决定 / 理由 / 反思
- 纪律：边问边记，原文即时存档，最后只补反思列

## 4. 图表体系（C1-C25）

25 张图表覆盖全部章节，配色遵循色盲安全规范：
8 槽分类色板（经 CVD 验证）、蓝色单色序（分层 10 组渐变）、明暗双主题各一套色值、
净值/回撤用双面板（禁止双轴）。交互：因子联动选择、dataZoom、图例勾选、热力图悬停。

## 5. 部署与验证

- 交付前走查：10 页 0 控制台错误、25 图渲染、notebook 全 PASS、线上 URL 验证
